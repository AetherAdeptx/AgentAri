# Project notes

FirstAgent is an experimental, from-scratch C++ AI and agent prototype.

The initial project structure and implementation were created collaboratively
with ChatGPT Luna. This repository is an early research snapshot and has not
been tested extensively. It has received local build, smoke, unit-test, and
sanitizer checks, but it is not production software and should be expected to
contain bugs, incomplete features, and changing interfaces.

The repository intentionally excludes local build directories, downloaded
dependency caches, and machine-specific data. Recreate those dependencies with
the documented build instructions instead of committing them to the project.
